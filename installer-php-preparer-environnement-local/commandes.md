
# Installation de PHP

## 1. Vérifier la version PHP

php -v

Résultat : PHP 8.5.9

## 2. Démarrer le serveur local

php -S localhost:8000

Résultat : Serveur PHP démarré avec succès.

## 3. Tester dans le navigateur

http://localhost:8000/test-serveur.php

Résultat : Environnement local PHP opérationnel.
